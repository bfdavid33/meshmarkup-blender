# Changelog

## 1.0.0 (October 2026)

First release.

- Send the scene, or only the selected objects, to MeshMarkup as a client review link, copied to the clipboard.
- Send again to update the same model and link; the client's open notes stay in place.
- Connect once with a code approved in the browser; no password goes through Blender.
- Export only: save a review-ready GLB (modifiers applied) anywhere, without an account.
- Respects Blender's "Allow Online Access" setting; nothing is sent without a click.
